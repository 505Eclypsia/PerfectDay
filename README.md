# Идеальный День — Backend API

REST API интеллектуального биоритмического планировщика дня на **FastAPI + SQLAlchemy + PostgreSQL**.  
Сервис рассчитывает физический (23 дня), эмоциональный (28 дней) и интеллектуальный (33 дня) биоритмы, определяет критические дни, адаптирует дневную сетку под хронотип (`lark`, `owl`, `pigeon`) и автоматически распределяет задачи по 30-минутным слотам (`08:00–22:00`).

---

## 1. Запуск в Docker (FastAPI + PostgreSQL)

Требования: установленный **Docker** и **Docker Compose**.

Из корневой папки проекта выполните:
```bash
docker compose up --build -d
```

Для работы с API откройте:
* **Swagger UI:** `http://127.0.0.1:8000/docs`

Для прекращения работы контейнера и удаления базы данных:
```
docker compose down -v
```

## 2. Быстрое заполнение тестовыми данными (`seed_api.py`)

Чтобы не создавать пользователя и задачи вручную, запустите скрипт заполнения:

```bash
python seed_api.py
```

Скрипт по HTTP выполнит полный сценарий:
1. Зарегистрирует нового пользователя (или войдёт, если передать существующие `--email` и `--password`).
2. Создаст 5 тестовых задач разных типов (`intellectual`, `creative`, `physical`, регулярную `routine` на будни).
3. Добавит ручной перерыв «Обед» (`13:00–14:00`).
4. Вызовет `POST /api/v1/schedule/generate` и выведет в консоль **логин, пароль, биоритмы и готовый таймлайн дня**.

Дополнительные параметры скрипта:
```bash
python seed_api.py --url http://127.0.0.1:8000 --date 2026-11-27 --chronotype lark
```

## 3. Основные эндпоинты (`/api/v1`)

| Группа | Метод и путь | Назначение |
| --- | --- | --- |
| Авторизация | `POST /api/v1/auth/register` | Регистрация и выдача JWT + профиля |
| Авторизация | `POST /api/v1/auth/login` | Вход по OAuth2 (`username` = email, `password`) |
| Профиль | `GET /api/v1/users/me` | Текущий пользователь |
| Профиль | `PATCH /api/v1/users/me` | Изменение имени, даты рождения или хронотипа |
| Биоритмы | `GET /api/v1/biorhythms` | Значения, критические циклы и советы дня (`?date=YYYY-MM-DD`) |
| Биоритмы | `GET /api/v1/biorhythms/today` | Биоритмы на сегодняшний день |
| Биоритмы | `GET /api/v1/biorhythms/forecast` | Прогноз на `1–31` день (`?start_date=...&days=7`) |
| Задачи | `POST /api/v1/tasks` | Создать задачу в бэклоге |
| Задачи | `GET /api/v1/tasks` | Список задач (опционально `?status=not_done\|on_repeat\|done`) |
| Задачи | `GET / PATCH / DELETE /api/v1/tasks/{id}` | Получение, редактирование и удаление задачи |
| Расписание | `POST /api/v1/schedule/generate` | Генерация или пересчёт плана на дату |
| Расписание | `GET /api/v1/schedule?date=YYYY-MM-DD` | Получить сохранённый план дня |
| Расписание | `POST /api/v1/schedule/slots` | Добавить ручной слот («Обед», «Отдых») |
| Расписание | `PATCH /api/v1/schedule/slots/{id}` | Перенести слот (с пересчётом дня) или отметить `done`/`missed` |
| Расписание | `DELETE /api/v1/schedule/slots/{id}` | Удалить слот из расписания |

## 4. Переменные окружения

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `POSTGRES_DB` | Имя базы данных PostgreSQL в Docker | `ideal_day` |
| `POSTGRES_USER` | Пользователь PostgreSQL в Docker | `ideal_day` |
| `POSTGRES_PASSWORD` | Пароль PostgreSQL в Docker (обязательно задать в `.env`) | — |
| `DATABASE_URL` | Строка подключения SQLAlchemy (для локального запуска без Docker) | `sqlite:///./ideal_day.db` |
| `JWT_SECRET_KEY` | Секрет для подписи JWT-токенов | Случайный ключ в памяти |
| `CORS_ORIGINS` | Разрешённые origin фронтенда через запятую | `http://localhost:5173,http://localhost:3000,http://127.0.0.1:5173` |
